無料ツール

アプリ Tova Translate に入っているのと同じ読み仮名エンジンを、そのままブラウザで使えるようにしたものです。無料、登録不要で、貼り付けた文章が端末の外に出ることはありません。

読みの変換

ピンイン変換中国語を貼り付けると、一文字ずつの上にピンインが並びます。簡体字・繁体字のどちらでも使え、読みが複数ある漢字は語の中での読みを選びます。…粤ピン変換広東語を貼り付けると、一文字ずつの上に粤ピンと声調番号が並びます。繁体字を前提に作られていて、香港で実際に書かれる口語の字——嘅、咗、喺、唔、佢——も読めます。…

ブラウザだけで使える読み仮名ツール

漢字は、その字自体が読み方を教えてくれません。日本語の漢字にも音読みと訓読みがあるように、中国語の漢字にも複数の読みを持つものがあり、意味が分かることと声に出せることは別です。ローマ字表記は、その音をラテン文字で字の上に書くことで、この隔たりを埋めます。

たとえば 谢谢 という字を看板で見て「ありがとう」の意味だと分かっても、それが xiè xie と発音されることまでは分かりません。日本語の音読みで「しゃしゃ」と読んでも中国では通じません。字面から意味は推測できても、音は推測できない——それが中国語の漢字です。

ここにある二つのツールは、まさにそれを行います。ひとつは標準中国語にピンインを、もうひとつは広東語に粤拼（ジュットピン）を付けます。テキストを貼り付けると、一文字ごとに読みが上に表示されます。すべてブラウザ上で動作し、辞書は最初の一度だけ読み込まれ、変換は端末内で完結します。貼り付けた内容がどこかに送信されることはありません。

使う人はさまざまです。中国語を学び始めた人、上海や台北、香港への旅行前に地名や料理名の読みを確かめておきたい人、授業用の資料を作る先生、中国語圏の同僚の名前を正しく呼びたい人。どの場合も、貼り付けて読みを確認するだけで済みます。

ピンイン変換ツール

漢語ピンインは標準中国語の公式なローマ字表記で、中国本土の辞書でも、ほぼすべての教科書でも使われています。簡体字でも繁体字でも、貼り付ければ一文字ずつ上にピンインが表示されます。声調記号つき、声調番号つき、声調なしのいずれかを選べます。

やっかいなのは読みが複数ある字です。长 は 长城（万里の長城）では cháng、长大（成長する）では zhǎng と読みます。一文字ずつ辞書を引くだけのツールは、ここで必ず間違えます。このツールは語単位で処理するため、その字が置かれた文脈が求める読みを返します。単に最も一般的な読みを返すわけではありません。

結果はそのままコピーできます。ピンインだけをコピーすることも、漢字とピンインを並べた形でコピーすることもできるので、単語帳や授業のプリント、メモにそのまま貼れます。一度に変換できるのは 5,000 文字までで、長い文章は分けて貼り付ければ問題ありません。

粤拼（ジュットピン）変換ツール

広東語は標準中国語とほぼ同じ漢字で書かれますが、発音はまったく異なります。そのため香港、マカオ、広州ではピンインは役に立ちません。粤拼は広東語のために作られたローマ字表記で、各音節の後ろに数字を付けて声調を示します。

広東語のテキストを貼り付けると、一文字ずつ上に粤拼が表示されます。唔該 は m4 goi1 となり、場面によって「ありがとう」にも「すみません」にもなる言葉です。音節だけが必要なときは、声調番号を非表示にできます。

ピンイン変換ツールと同じく語単位で読みを判定するので、「銀行」は一字ずつ引いたときの ngan4 hang4 ではなく ngan4 hong4 になります。嘅、咗、喺、冇、嘢 のような、香港で日常的に書かれる広東語の口語字も収録しています。標準中国語向けの辞書では、たいていここで引けなくなります。

ピンインと粤拼、どちらを使うか

文字の見た目ではなく、行き先で選んでください。漢字自体はどちらもほぼ同じです。中国本土と台湾は標準中国語なのでピンイン、香港とマカオは広東語なので粤拼です。広州や広東省の多くの地域では、その両方が使われます。

広東語をピンインで表記すると、広東語の単語を標準中国語の発音で読んだものになり、香港では通じません。他のツールはこの置き換えを黙って行うことがあるので、はっきり書いておきます。

台湾で話されているのも標準中国語なので、ピンインで問題ありません。ただし台湾の学校では注音符号（ㄅㄆㄇㄈ）という別の表記が使われており、表しているのは同じ発音です。また「垃圾」「星期」のように中国本土と台湾で読みが異なる語が少数あり、このツールが示すのは中国本土の標準的な読みです。

よくある質問

このツールは無料ですか。

無料です。登録もアプリのインストールも不要で、使える回数にも制限はありません。ページを開けばそのまま使えます。

貼り付けた内容はアップロードされますか。

いいえ。辞書は最初にツールを使うときブラウザに読み込まれ、それ以降の変換はすべて端末内で行われます。貼り付けた内容が送信されることはありません。

繁体字にも対応していますか。

対応しています。簡体字と繁体字のどちらでも構いませんし、どちらを使っているか指定する必要もありません。

思っていたのと違う読みが表示されるのはなぜですか。

一文字単位ではなく語単位で処理しているためです。複数の読みを持つ字は、その語が求める読みになります。ほとんどの場合それが目的の読みです。読みが本当に曖昧な場合は、候補が併記されます。

オフラインでも使えますか。

辞書がいったん読み込まれれば、変換自体に通信は不要です。画面上にない文字——メニューや道路標識——については、Tova Translate がスマートフォンのカメラで読み取り、中国本土でも VPN なしでオフラインのまま使えます。

一度にどれくらいの分量を変換できますか。

一度に 5,000 文字までです。長い文章は分けて貼り付けてください。区切った部分ごとに結果をコピーできます。

文字が画面の中にないときは

このツールは貼り付けられる文字だけを扱います。Tova Translate はカメラで同じことをします。メニューや看板にかざせば、カメラ画面下部のパネルに一文字ずつの読みが各字の上に表示され、翻訳も一緒に出ます。中国本土ではオフラインでも動き、VPN は要りません。
